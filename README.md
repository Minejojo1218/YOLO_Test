## 系统简介

YoloStudio 是一款面向 Windows 的桌面级计算机视觉工具，把 **图像标注 → 图像预处理 → 模型训练 → ONNX 导出 → 模型验证** 串成一条龙。基于 **Qt 6.9.1 + MSVC2022** 开发，训练/导出调用本机 Python（Ultralytics）完成，**推理使用 OpenCV DNN 直接在 C++ 中运行 ONNX**（不依赖 Python）。

平台聚焦 **目标检测（Detect）** 与 **实例分割（Segment）** 两类任务，覆盖缺陷检测、缺陷轮廓分割、工业质检等场景；提供框 / 多边形 / 自由绘制三种标注方式，内置 AI 辅助预标注、数据清洗与图像预处理，训练过程可视化（损失 / mAP 曲线），推理结果同时输出检测框与**缺陷实际轮廓**。

### 核心特性

| 特性 | 说明 |
|------|------|
| 一站式流程 | 标注 → 预处理 → 训练 → 导出 → 验证全流程贯通，无需切换工具 |
| 三种标注方式 | 矩形框、多边形点选闭合、**自由绘制**（画笔随手描，自动简化成多边形） |
| AI 辅助预标注 | 用已导出的 ONNX 模型对图片自动生成标注，支持检测框与分割轮廓 |
| 数据预处理 | 镜像 / 旋转 / 亮度 / 对比度 / 反色 / 灰度 / 模糊 / 锐化，链式步骤 + 前后对比预览 + 批量应用 |
| 数据质量清洗 | 自动检测标签异常、类别/坐标越界、图片损坏，统计类别分布，一键重建 data.yaml |
| 零 Python 推理 | OpenCV DNN 直接加载 ONNX，C++ 推理，部署无需 Python 环境 |
| 全异步推理 | 推理与摄像头采集均在工作线程执行，界面不卡顿 |
| 训练可视化 | 损失曲线、mAP 曲线、最优轮次标记，实时日志 |
| 双主题界面 | 深色 / 浅色主题一键切换并记忆 |

## 功能特性

### 1. 数据集与数据标注

| 功能 | 说明 |
|------|------|
| 项目管理 | 新建/打开项目，图片导入，记忆上次项目路径 |
| 框标注 | 拖拽绘制矩形框；点击移动、右键改类别/删除 |
| 多边形标注 | 单击加点、双击/右键/回车闭合；拖动顶点微调、整体移动 |
| 自由绘制 | 按住左键沿缺陷边缘描边，松手自动 Douglas-Peucker 简化成多边形 |
| 撤销 / 重做 | `Ctrl+Z` / `Ctrl+Y`，覆盖绘制、移动、改类别、删除、AI 预标注 |
| AI 预标注 | 选 ONNX 模型 + 置信度，对当前图生成标注并追加到画布（可撤销） |
| 类别管理 | 添加 / 重命名 / 删除类别，自动同步 `classes.txt` 与 `project.json` |
| 图片管理 | 左侧列表显示标注状态；右键删除单张图片（含标签） |

### 2. 图像预处理

| 功能 | 说明 |
|------|------|
| 处理步骤 | 镜像(水平/垂直)、旋转(90°/180°/270°)、亮度、对比度、反色、灰度、高斯模糊、锐化 |
| 步骤链 | 添加 / 删除 / 上移 / 下移，参数可调，按顺序叠加 |
| 前后对比 | 原始图像 / 处理后 实时预览 |
| 批量应用 | 单张或全部图片一键处理 |
| 标签同步 | **镜像/旋转会同步转换标签坐标**（框与多边形），像素类操作标签不变 |
| 安全输出 | 输出到独立目录（`images/` + `labels/`），不覆盖原项目，可直接作为新数据集打开 |

### 3. 数据清洗

| 功能 | 说明 |
|------|------|
| 状态检查 | 未标注 / 标签异常（文件损坏） / 类别越界 / 坐标越界 / 图片损坏 |
| 类别分布 | 统计各类别实例数，快速发现类别不平衡 |
| 批量删除 | 勾选异常图片批量删除（图片 + 标签） |
| 划分重建 | 一键重新生成 `train.txt` / `val.txt` / `data.yaml` |

| 功能 | 说明 |
|------|------|
| 模型架构 | YOLOv8 / YOLO11 / YOLO12 / YOLO26 全系列（n/s/m/l/x），含 `-seg` 分割模型 |
| 基础参数 | epochs、batch、imgsz、设备（GPU / CPU / 多卡 `0,1`）、优化器、学习率、workers、AMP |
| 训练策略 | 早停 patience、warmup、lrf、momentum、weight decay |
| 数据增强 | mosaic、水平/垂直翻转、旋转、HSV 色调/饱和/亮度、平移、缩放、剪切、MixUp、Copy-Paste |
| 断点续训 | 选择 `last.pt` 恢复优化器与学习率进度继续训练 |
| 环境检测 | 检查 Python / PyTorch / CUDA / GPU / ultralytics 版本 |
| 训练监控 | 实时日志；损失曲线（box/cls/dfl）与 mAP 曲线，标注最优轮次 |

## 安装

### 1. 获取代码

```bash
git clone https://github.com/Minejojo1218/YOLO_Test.git
cd YOLO_Test
```

> 仓库包含 Qt 工程源码、`backend/` 后端脚本与 `scripts/` 环境脚本；
> `deps/`（OpenCV）、`runtime/`（Python 虚拟环境）、`datasets/` 为本地依赖与数据，不入库。

### 2. 把 OpenCV 放到 `deps/`

将 OpenCV 4.10 的 Windows 预编译包（`opencv_world4100.dll/lib`）放到：

```
deps/opencv4.10/x64/vc16/{bin,lib}
deps/opencv4.10/include
```

### 3. 配置 Python 环境（一次性）

双击运行 `scripts\setup_env.bat`，脚本会自动：

1. 在项目根目录创建 `runtime\` 虚拟环境；
2. 安装 CUDA 版 PyTorch（默认 cu126）与 ultralytics；
3. 校验 `cuda_available` 是否为 `True` 并显示显卡名。

> **RTX 50 系列**：编辑 `scripts\setup_env.bat`，把 `cu126` 改为 `cu128` 后重新运行。

### 4. 编译程序

1. 用 **Qt Creator 17** 打开 `CMakeLists.txt`（推荐；`.pro` 为备用）；
2. 选择 Kit **Qt 6.9.1 MSVC2022 64bit**，构建 **Release**；
3. CMake 已配置自动拷贝 OpenCV 运行时 DLL；若用 qmake 构建，可运行
   `scripts\copy_dlls.bat <输出目录>` 复制 DLL。

### 5. 运行

运行 `YoloStudio.exe` 即可（首次使用建议按下面「快速开始」走一遍）。

## 快速开始

1. **数据集页** → 新建/打开项目 → 导入图片 → 添加类别；
2. 选择标注模式（框 / 多边形 / 自由绘制）完成标注；也可用 **AI 预标注** 快速生成后人工复核；
3. 点 **「生成 data.yaml」** 生成训练划分；
4. **训练页** → 选择模型（如 `yolov8n.pt` / `yolov8n-seg.pt`）与参数 → 开始训练；
   可在「训练曲线」页签查看损失与 mAP 曲线；
5. 训练完成（或中断后）→ **导出页** → 选择权重 → 导出 ONNX；
6. **推理 · 评估页** → 选择 ONNX → 单张 / 文件夹 / 摄像头推理，或跑「验证集指标」；
7. （可选）**数据集页 → 图像预处理**：镜像/旋转/亮度等批量处理，输出新数据集目录。

## 数据格式

- **框标注**：YOLO 归一化 `class_id cx cy w h`（每行一个框）。
- **多边形标注**：YOLO-seg 归一化 `class_id x1 y1 x2 y2 ... xn yn`（每行一个多边形，至少 3 个点）。
- **同一切分文件统一格式**：ultralytics 不允许同一文件混用框与多边形格式，因此保存时只要该图含
  多边形，框会**自动转为四角多边形**、整文件按多边形格式写；纯框文件保持框格式。
- **分割模型训练**要求每个已标注图都有多边形（纯框文件会被 ultralytics 拒绝）——训练 `-seg` 模型时
  请用「多边形标注」或「自由绘制」。
- 类别：`classes.txt`（每行一个类别）。
- 训练配置：`data.yaml`（自动生成，`train.txt`/`val.txt` 为划分清单）。

## 常见问题

**Q1：训练报「找不到标签 / 数据集为空」？**

只有**已标注**的图片会进入训练集；请先在数据集页完成标注并点击「生成 data.yaml」。

**Q2：训练跑不起来 / CUDA 不可用？**

训练页点「环境检测」确认 `CUDA: 可用`；再检查 `scripts\setup_env.bat` 的校验输出
（`cuda_available=True`）。RTX 50 系需把脚本中的 `cu126` 改为 `cu128`。

**Q3：训练中断了怎么继续？**

训练页点「断点续训...」，选择 `runs/xxx/weights/last.pt`，会恢复优化器、学习率与训练进度。

**Q4：mAP 很高但推理看不到框？**

YOLO26 / RT-DETR 等端到端模型默认导出的 ONNX 含 TopK 节点，OpenCV DNN 4.10 无法解析。
请用新版程序重新「导出 ONNX」（导出脚本会自动关闭 end2end 分支，转为经典 NMS 格式）。

**Q5：想要输出缺陷的实际轮廓（掩码）？**

选择**分割模型**训练（如 `yolov8n-seg.pt`），并用「多边形标注」或「自由绘制」精细描出缺陷边缘；
导出后推理会自动画出掩码轮廓。用「框标注」也能训练分割模型，但轮廓会贴近框形。

**Q6：AI 预标注结果不准？**

检查模型类别顺序是否与当前项目类别一致，并适当降低置信度阈值后重试。

**Q7：摄像头推理卡顿？**

摄像头采集与推理已全部放入工作线程；帧率受模型推理速度限制，可换更小模型或降低分辨率。
